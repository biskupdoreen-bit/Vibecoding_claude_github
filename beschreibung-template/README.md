# Vorlage für einen neuen Fall

So starten Sie:
1. Klicken Sie auf "Use this template" und legen Sie ein neues, privates Repository an.
2. Füllen Sie BESCHREIBUNG.md aus (Block 3).
3. Lassen Sie Claude Code mit dem Prompt aus PROMPT.md erst Rückfragen stellen.
4. Bauen Sie die erste Version, prüfen Sie sie mit TESTFAELLE.md (Blöcke 4 und 5).
5. Bewerten Sie am Ende mit EINSATZREIFE.md (Block 7).

Keine echten Daten oder Namen in die Vorlage schreiben.
