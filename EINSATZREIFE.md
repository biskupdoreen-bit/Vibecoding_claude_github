# Einsatzreife

Ein Prototyp ist noch kein Einsatz. Jedes Nein und jedes Unklar wird zu einem offenen Punkt mit Zuständigkeit und Termin.

| Prüffeld | Frage | Antwort (Ja / Nein / Unklar) | Offener Punkt | Zuständig bis |
|----------|-------|------------------------------|---------------|---------------|
| Datenschutz | Kommen personenbezogene Daten vor? | | | |
| Speicherort und Sichtbarkeit | Wer sieht Repository, Seite und Meldungen? | | | |
| Sicherheit | Wer darf lesen, schreiben, löschen? | | | |
| Qualität | Sind alle Testfälle bestanden? | | | |
| Pflege | Wer kümmert sich nach dem Schulungstag? | | | |

## Ergebnis
- Grün: Alles beantwortet, keine personenbezogenen Daten, Pflege geregelt. Mit der IT abstimmen, dann Pilot im kleinen Kreis.
- Gelb: Offene Punkte, aber klärbar. Punkte mit Zuständigen und Termin festhalten.
- Rot: Datenschutz oder Zuständigkeit ungeklärt. Prototyp bleibt Lernstand, Fall mit der IT besprechen.

Gesamtergebnis: [Grün / Gelb / Rot]

Die Checkliste ersetzt keine Prüfung durch Datenschutz und IT.
